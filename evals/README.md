# 方法层行为回归

每个目录是一个虚构站点的诊断场景，用来检查 Skill 是否把 Agent 带到正确的链路上，而不是检查某个站点能否采到。场景里的域名、头名和错误码都是编造的，不写真实站点。

目录格式与 `claude plugin eval` 一致：`prompt.md` 是任务，`case.yaml` 写好结果的样子，`graders/` 每个文件一条可判定的断言。

改动路由表、实验纪律或相关方法文档后，用新旧两版各跑一遍同样的场景比较。流程见 [agent-validation.md](../references/agent-validation.md)。

断言按评分者的反馈持续修正：太弱、太严或题面没有引出的断言都要改。改过断言后，旧的分数不能和新的分数直接比较。

每轮把答案匿名后交给不知道版本的评分者。这些场景的断言围绕本 Skill 的方法编写，分差说明行为确实变了，不等于真实任务的效果提升幅度。
