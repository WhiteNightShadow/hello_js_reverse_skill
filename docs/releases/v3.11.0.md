## 版本说明

Skill 名称从 `hello_js_reverse_skill` 改为 `hello-js-reverse-skill`，符合 Agent Skills 命名规范，pi 等按规范校验的工具加载时不再提示名称不规范。方法内容和默认行为不变。

## 主要变更

- `SKILL.md` 的 `name` 改为 `hello-js-reverse-skill`。规范要求名称只用小写字母、数字和连字符，旧名称里的下划线会让 pi 提示 `name contains invalid characters`。
- 安装说明改为克隆到 `hello-js-reverse-skill` 目录。规范还要求目录名和 `name` 一致，仓库名不变，所以克隆时要写明目录名。

## 兼容性

- 已经装在 `hello_js_reverse_skill` 目录的，更新后把目录改名为 `hello-js-reverse-skill`。不改名时 pi 仍会加载，但会提示名称和目录不一致。
- Claude Code 的 `/` 菜单里显示为 `/hello-js-reverse-skill`；目录没改名时，用旧目录名也还能调用。
- 模板目录、脚本和引用路径都没变，配套 MCP 不变。

## 验证

- 用 pi 0.73.1 的 skill 加载代码检查：v3.10.0 在 `hello_js_reverse_skill` 目录下提示 `name contains invalid characters`，和 issue 里的截图一致；新版放在 `hello-js-reverse-skill` 目录下没有提示；新版留在旧目录时照常加载，只提示名称和目录不一致。
- 51 项 Python 脚本与文档门禁测试、40 项 Python 模板测试、3 项 Node 测试和 4 个模板离线测试通过。
