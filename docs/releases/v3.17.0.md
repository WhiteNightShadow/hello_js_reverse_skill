## 版本说明

合入通用化脱敏重构后的 [#12](https://github.com/WhiteNightShadow/hello_js_reverse_skill/pull/12) 与 [#13](https://github.com/WhiteNightShadow/hello_js_reverse_skill/pull/13)，沉淀 **动态 `eval` 打包壳脱壳与三层独立密钥域分离**、**无填充 3 字节探针恢复自定义 Base64 字母表**、**多状态码与空壳响应门禁分层归因**、**双代 JSVMP 前缀判读与字节码容器拆解** 及 **`jsdom` 空种子退化串 S1 断言与快照式 `setter` 多写捕获** 方法与两篇通用脱敏案例，并将 MCP 工具契约与快照同步至 [camoufox-reverse-mcp v1.13.0](https://github.com/WhiteNightShadow/camoufox-reverse-mcp/releases/tag/v1.13.0)（43 个工具）。

## 主要变更

- **不透明令牌编码、双代前缀判读与多层密钥域分离（`references/opaque-token-analysis.md`）**：
  - **Latin-1 → UTF-8 二次编码膨胀与三层独立密钥域分离**：补充等长流密码经 Latin-1 转 UTF-8 再进 Base64 时约 `1.5×` 长度膨胀与 `0xC2..0xC3` 双字节识别方法，以及同接口查询参数摘要、绑定会话与 UA 族的请求体流式信封、静态掩码表加 `zlib` 响应解码三套独立密钥域的分拆标定规程。
  - **`[i << 2, 0, 0]` 黑盒恢复 64 项自定义 Base64 表与双代容器拆解**：补充对剥离前缀后的底层字节编码入口喂入 64 组无填充 3 字节探针恢复完整字母表（含高位切位与 `[0]` 尾填充校验），以及通过置空环境探针区分“并存双代字节码程序”与“环境风险评级”、拆解自定义二进制容器（魔数、隐写掩码位、字节序代码长度与前缀码常量池）的方法。
- **多状态码门禁分层归因与单次配额边界（`references/protocol-analysis.md`、`references/signature-source-isolation.md`）**：
  - 补充固定同一份新鲜有效签名在浏览器级 TLS 模拟客户端、普通 HTTP 客户端与单字段摘除（`R0`）之间建立“错误码 ↔ 门禁层（传输门 / 必带公共设备信封 / 动态签名门 / 跨地域会话域）”归因表的步骤；
  - 区分服务端「一凭据一请求」单次消费配额、短窗高频冷却恢复（冷却后同一令牌复发仍成功）与同名异源设备标识字段。
- **动态 `eval` 脱壳与 `jsdom` 运行时边界（`references/obfuscation-guide.md`、`references/original-sdk-runtime.md`）**：
  - 补充离线 `node:vm` 接管顶层打包壳与直接/间接 `eval` 词法作用域边界，串联 `extract_script` 提取 `fetch`+`eval` 异步 JSON 脚本落盘与离线改写回灌；
  - 补充空种子下静默产出的 9 字符退化兜底串 S1 结构断言、独立观察会话下拷贝 `Uint8Array`/`ArrayBuffer` 快照的属性 `setter` 多写序列捕获、受控本地 `ResourceLoader` 子资源挂载，以及避免给 `window` 套全局 `Proxy`（破坏 `typeof`/`in` 一致性）与极简 `JSDOM` WebIDL 节点查找排障边界。
- **配套 `camoufox-reverse-mcp v1.13.0` 契约同步与通用脱敏案例（`references/`、`cases/`、`tests/`）**：
  - 同步 43 个工具 schema 快照（`references/mcp-tools.json`），在 `references/mcp-tool-reference.md` 与 `references/browser-evidence-contract.md` 记录 `extract_script`、`evaluate_js(output_file=...)`、`cookies(action="header", output_file=...)`、`wait_for(mode="request")` 及死会话自动恢复（`recovered_stale_session=True`）契约边界；
  - 新增两篇通用脱敏案例 `cases/eval-packer-unwrapping-and-multilayer-codec-separation.md` 与 `cases/custom-b64-envelope-dual-gen-vmp-and-container-disassembly.md`，扩充 `tests/test_skill_docs.py` 敏感词防泄漏门禁并将脱敏案例基数提升至 6 篇。

## 兼容性

- 原有工作流、入口行数预算（`SKILL.md < 220` 行）与模板目录保持不变；`extract_script`、`evaluate_js(output_file=...)`、`cookies(action="header")` 与 `wait_for(mode="request")` 需配套 `camoufox-reverse-mcp >= 1.13.0`。
