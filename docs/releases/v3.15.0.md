## 版本说明

合入脱敏重构后的 [#9](https://github.com/WhiteNightShadow/hello_js_reverse_skill/pull/9)，沉淀 **jsdom 子 Realm / 原型链 / `document.all` 原生性自证补丁** 与 **测量防污染、定长码点流逐槽反解消融** 方法及通用脱敏案例，并将 MCP 工具契约快照同步至 [camoufox-reverse-mcp v1.11.1](https://github.com/WhiteNightShadow/camoufox-reverse-mcp/releases/tag/v1.11.1)。

## 主要变更

- **jsdom 沙箱原生性与子 Realm 校准方法（`references/jsdom-env-patches.md`、`references/original-sdk-runtime.md`）**：
  - **同源 `iframe` 子 Realm 修补（`1.1`）**：同时拦截 `HTMLIFrameElement.prototype` 的 `contentWindow` 与 `contentDocument`（防止经 `contentDocument.defaultView` 绕过），将 `childWin.EventTarget` 归位到子 Realm 的 `Function.prototype`，在保留非函数 `this` 抛出子 Realm `TypeError` 的前提下递归标记子窗口构造器、DOM 原型链与嵌套 `iframe`。
  - **实例自有属性与原型链描述符对齐（`1.2`）**：厘清多余自有属性的常见来源（手写补丁误将 `Document.prototype` 属性挂在实例上或 `[LegacyUnforgeable]` 差异），按 `evaluate_js(..., world="main")` 采集的真实页面描述符快照把原型属性迁移回原型链并保留已打补丁的 getter/value，对真实缺失的全局构造器保持 `undefined`。
  - **`Document.prototype.all` 引擎级 undetectable 与不可删活索引（`1.3`）**：将 `all` 定义在 `Document.prototype` 上避免污染 `document` 自有属性，通过 `node --allow-natives-syntax` 的 `%GetUndetectable()` + 原型 `Proxy` + 有效下标 `0..len-1` 的 `configurable: false` 同步满足活性集合与 `delete` 后复读语义。
  - **忙等时钟与高频探针自伤边界**：含忙等循环的目标改用「固定初值 + 单步微小递增」；热寄存器探针改用内联整数计数器 + 步数窗口门控避免回调改变产物。
- **测量防污染与定长码点流逐槽消融（#9）**：
  - `references/browser-evidence-contract.md`：补充 `instrumentation(action="install")` 跨导航持续生效的核查边界（明确 `check_environment()` 的 `browser.has_residuals` 不涵盖活动插桩路由，且激活期间 `scripts(action="get"|"save")` 会拉取到改写产物），区分行为观察会话与载荷基线会话。
  - `references/controlled-experiments.md`、`references/opaque-token-analysis.md`：补充定长码点流跨 `0x80` UTF-8 单/多字节边界产生浮动长度 Base64 串的结构判读，以及「同序号干净采样 → 逆向解包到槽位层 → 同侧 A/A 过滤自抖动槽 → 稳定差异槽单点消融」步骤。
  - `cases/bitpacked-dual-vmp-slot-diff-and-realm-nativeness.md`：新增已彻底去除站点域名、接口路径、参数名、返回码及单版本槽位常量的通用脱敏案例；`tests/test_skill_docs.py` 新增 `test_desensitized_cases_do_not_leak_site_terms` 防回流门禁。
- **契约同步**：`references/mcp-tools.json` 与 `references/mcp-tool-reference.md` 同步至 `camoufox-reverse-mcp v1.11.1`（42 个工具）。

## 兼容性
