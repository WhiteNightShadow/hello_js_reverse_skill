## 版本说明

把 Skill 的主干从“按工具组织”改成“按问题路由”：先判断问题在哪一层，再走对应链路，用对照实验收口。站点规则退回案例层，默认行为不变。

## 主要变更

- SKILL.md 重写为成功分层、问题路由表、路线阶梯和实验纪律，工具级细节移入 `references/browser-evidence-contract.md`。
- 新增五份方法文档：对照实验、签名来源隔离、原始 SDK 运行、不透明令牌分析、参数跟踪，以及脱敏案例和 `templates/param-tracking/` 模板。
- 新增 `scripts/experiment-ledger.py`（在线门禁、尝试台账、单变量回读）和 `scripts/opaque-token-inspect.py`（令牌批次结构分析）；`project-baseline.py` 支持 `--identity` 分开记录版本身份。
- 吸收公开 skill 库的并联闸门、概率门、A/A 与阳性对照、改写分级判定等方法，出处和证据状态见 [调研记录](https://github.com/WhiteNightShadow/hello_js_reverse_skill/blob/v3.10.0/docs/research/2026-11-public-skill-survey.md)。
- 清理把单站经验写成全局规则的内容；旧的 30 条经验法则移入 `cases/`，并逐条标明去向；修正已失效的工具名和参数。新增文档门禁测试防止回退。

## 兼容性

- 保留 hello_js_reverse_skill 名称、模板目录和原有引用路径，`experience-rules-full.md` 改为去向索引。
- 配套 MCP 仍为 v1.8.0，旧工作流按对应工具 schema 使用。
- `analyze_cookie_sources` 在 MCP v1.8.0 源码中存在但未注册，文档改为手动归因。`navigate(pre_inject_hooks=[...])` 的 Cookie 钩子名是 `cookie_hook`。
- Skill 名称含下划线，不符合 agentskills 命名规范，为兼容已有安装暂时保留。

## 验证

- 51 项 Python 脚本与文档门禁测试、40 项 Python 模板测试、3 项 Node 测试和 4 个模板离线测试通过。工具契约快照本轮未改，未重跑对比。
- 8 个虚构诊断场景，新旧两版各由独立 Agent 作答一次，答案匿名后交独立评分者：新版通过 45/48 条断言，旧版 28/48，没有一条是旧版过而新版没过，平均 token 少约 8%。
- 3 个有失败的场景用定稿前的版本和收紧后的断言复验，通过 15/18。其中一条暴露的方法缺口已补上，这句改动没有再次复验。
- 断言围绕本 Skill 的方法编写，分差说明行为确实变了，不等于真实任务的提升幅度。本轮没有在真实站点上验证，没有优化 description 的触发率。
