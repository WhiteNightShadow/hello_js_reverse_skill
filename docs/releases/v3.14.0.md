## 版本说明

配合 [camoufox-reverse-mcp v1.11.0](https://github.com/WhiteNightShadow/camoufox-reverse-mcp/releases/tag/v1.11.0) 补充协议级原生断点调试（如 `rdp_debugger`）的证据边界与工具快照，并合入脱敏重构后的「等长字节码流式护甲 + 粗粒度布尔判决分层归因」方法与案例。

## 主要变更

- **原生断点调试的证据边界与快照同步**：
  - `references/browser-evidence-contract.md`：新增「原生断点调试：仅用于独立观察会话」，对比源码插桩、原生属性追踪与原生断点调试三者的适用面，并明确五条边界——独立于 Playwright 的浏览器进程与目录、暂停拉大真实时钟间隔对时间差检测的影响、`source_url` 与 `sourceId`（`eval` / `new Function`）跨刷新重挂差异、1-based 列号向 0-based 可停列吸附，以及配置继承降级与 `unix_socket=True` 本地权限隔离。
  - `references/path-a-four-tools.md`、`references/mcp-tool-reference.md`、`references/mcp-tools.json`：补充何时在独立观察会话做单次暂停抓拍，并将工具契约快照同步至 MCP v1.11.0（42 个工具）。
- **不透明令牌与布尔黑盒归因方法补充（#8）**：
  - `references/opaque-token-analysis.md`：补充「固定初始状态 + 恒定压缩头/键前缀经流式变换产生固定密文前缀（静态搜不到魔数常量）」与「等长无填充密文的同会话往返验证及动态字段依赖核实」。
  - `references/controlled-experiments.md`：新增「粗粒度布尔判决下的分层锁死」，明确外层编码往返锁死 → 单位换算实测标定 → 当前目标真实基线分布对照的三步隔离顺序，强调不跨站点套用单次样本的统计阈值。
  - `cases/vm-stream-armour-and-boolean-oracle-isolation.md`：新增已彻底去除厂商、域名、参数名、构建常量和单站经验阈值的脱敏案例；`tests/test_skill_docs.py` 增补厂商词门禁。
- **贡献者致谢**：`README.md` 新增「社区贡献者」章节，致谢 [@Moojing-jianchuan](https://github.com/Moojing-jianchuan)。

## 兼容性

- 原有工作流与模板路径不变；`rdp_debugger` 需已安装 `camoufox-reverse-mcp >= 1.11.0`，旧版 MCP 不包含该工具。
