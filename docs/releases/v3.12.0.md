## 版本说明

新增平坦化分发的阶段对照：配合 camoufox-reverse-mcp v1.9.4 的 `tap_stage_calls`，把浏览器和本地补环境各自的状态序列逐条比对，第一个不同的状态就是分叉点。本地算出的值和浏览器不同、读到的属性又对不出差别时，可以用它缩小范围。

## 主要变更

- `references/jsvmp-source-instrumentation.md` 新增 4.5 节：安装和读日志的步骤，怎么确认改写生效，事件的记录规则和匹配范围，以及本地侧按同样规则记录状态序列的示例代码。
- `references/path-b-env-emulation.md` 的要点里加了一条指向阶段对照；`references/mcp-tool-reference.md` 补上 MCP v1.9.x 的变化。
- `references/mcp-tools.json` 工具快照从 v1.8.0 更新到 v1.9.4：`instrumentation` 多了 `tap_stage_calls`；`launch_browser` 没传的参数改用服务端启动参数，快照里不再写默认值。

## 兼容性

- 阶段对照需要 camoufox-reverse-mcp v1.9.4，`SKILL.md` 的 `mcp-compatible` 已注明。其余方法、模板和脚本不变，旧版 MCP 照常可用。

## 验证

- 51 项 Python 脚本与文档门禁测试、40 项 Python 模板测试、3 项 Node 测试和 4 个模板离线测试通过。
- `scripts/check-mcp-contract.py` 对 camoufox-reverse-mcp v1.9.4 检查通过，快照与工具定义一致。
- 4.5 节的本地示例代码原样取出，在 Node 里对一个小型平坦化 VM 运行：记录的状态号、参数个数和返回值序列与 MCP 浏览器日志逐条一致（11 条），计算结果相同。
