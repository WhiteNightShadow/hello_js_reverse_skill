## 版本说明

配合 camoufox-reverse-mcp v1.10.0 更新插桩、preset 和环境对齐的用法，并新增环境包套用模板：用 `compare_env(output_path=...)` 从真实浏览器导出的环境包，可以直接套到本地 jsdom 上。

## 主要变更

- 新增 `templates/env-bundle/`：`applyEnvBundle(window, bundle)` 只套包里真实采到的值，navigator 和 screen 定义在原型上，plugins 和 mimeTypes 按列表重建，CSS 补上声明原型缺的属性名和 enumerable 标志；返回报告列出套用了什么、跳过了什么、窗口缺哪些全局名。canvas 像素、WebGL 绘制、音频和时区不伪造。用法写在 `references/environment-patch.md` 第 7 节。
- `references/jsvmp-source-instrumentation.md`、`path-a-four-tools.md`：插桩默认只记读取（调用改写会改变 `caller` 和递归深度）、大文件阈值 2MB 和 `skipped_files`、同源 iframe 的事件进顶层日志、按 `seq_window`/`stage` 切片、`dropped`；阶段对照可以用 `rewrite_source` 生成本地插桩文件，用 `stage_break` 记下某个状态的完整参数。
- `references/analysis-scenarios.md`、`jsvmp-analysis.md`、`mcp-tool-reference.md`：preset 装在页面主世界后的读法和适用范围、环境包导出；`references/mcp-tools.json` 工具快照更新到 MCP v1.10.0（41 个工具）。

## 兼容性

- 新写法需要 camoufox-reverse-mcp v1.10.0，`SKILL.md` 的 `mcp-compatible` 已注明；用旧版 MCP 时照旧显式传 `rewrite_calls=False`、按旧阈值处理大文件。
- 环境包套用模板只依赖 jsdom，离线自测不需要安装依赖。

## 验证

- 51 项 Python 脚本与文档门禁测试、40 项 Python 模板测试、3 项 Node 测试和 5 个模板离线测试通过（新增的环境包模板已加进 CI）。
- `scripts/check-mcp-contract.py` 对 camoufox-reverse-mcp v1.10.0 检查通过，快照与 41 个工具定义一致。
- 用 MCP v1.10.0 在真实浏览器（Camoufox 0.5.9，无头）导出的环境包，在 jsdom 24 上套用：userAgent、platform、languages、hardwareConcurrency、webdriver、plugins、mimeTypes、screen、窗口尺寸和像素比 10 项都和包里一致，navigator 实例自身没有属性；只记了类型的 16 项（如 permissions、mediaDevices）列在跳过清单里。jsdom 的 style 能 for...in 出 1853 个名字，比浏览器的 1172 个多，模板去不掉多出来的，报告里会提示。
