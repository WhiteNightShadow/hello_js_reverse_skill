## 版本说明

合入通用化脱敏重构后的 [#10](https://github.com/WhiteNightShadow/hello_js_reverse_skill/pull/10)，沉淀 **按会话重编译多态 JSVMP 观测与运行期窗口密钥自证**、**跨引擎 `Error.stack` 格式对齐** 以及 **多槽联合阈值门禁下的 Step 0 往返自证与金标准折半消融** 方法及通用脱敏案例，并将 MCP 工具契约与快照同步至 [camoufox-reverse-mcp v1.12.0](https://github.com/WhiteNightShadow/camoufox-reverse-mcp/releases/tag/v1.12.0)。

## 主要变更

- **联合评分门禁反向消融与多态 VM 密钥自证（`references/controlled-experiments.md`、`references/opaque-token-analysis.md`）**：
  - **多槽联合阈值门禁与金标准反向消融**：当服务端对多槽做联合与门或加权风险分判定导致单向单修无梯度时，先以发送前截断的未消费真机样本完成 **Step 0 原样解包重打包往返自证**（排除加解密失真或测试脚手架覆盖会话绑定字段），再通过成组折半退化在对数级预算内定位敏感槽位集合。
  - **多态字节码内嵌分组密钥提取**：针对每次下发重排字节哈希与偏移的多态脚本，补充运行期定长 32 位寄存器窗口读频采样与同次密文结构不变量（合法 UTF-8、可打印 ASCII 占比与分隔符/JSON 语法）离线自证提取方法。
- **跨内核 `Error.stack` 格式对齐与基线实测等价性（`references/jsdom-env-patches.md`、`references/original-sdk-runtime.md`）**：
  - **新增 `patchErrorStackFormat` 可选补丁（`1.4`）**：同时支持 `jsdom` 与裸 `node:vm`（解析子 Realm 内建 `%Error%` 以覆盖引擎自抛 `TypeError`），过滤 `node:` 与本地路径宿主帧，将 `stackTraceLimit` 与 `prepareStackTrace` 设为 `enumerable: false`，并对齐 SpiderMonkey 尾随换行格式，消除内部栈正则失配引发静默 `try/catch` 写槽污染。
  - **抗指纹基线实测等价性**：明确画布/WebGL 返回值以当前基线浏览器实测输出（含抗指纹全零摘要）为准，避免盲目换入第三方原生渲染库破坏已对齐槽位。
- **配套 `camoufox-reverse-mcp v1.12.0` 契约同步（`references/jsvmp-source-instrumentation.md`、`references/browser-evidence-contract.md`、`references/mcp-tool-reference.md`、`references/mcp-tools.json`）**：
  - 新增 `4.6` 节说明 `instrumentation(..., inject=[{find, before, after, group}])` 源码级结构正则插桩（四层安全保护与状态诊断字段）及 `intercept_request(..., mock_response={"body_file": ...})` 大体积改造脚本按请求重读快迭代；
  - 补充 `rdp_debugger` 的 `url_pattern` + `find`（+ `occurrence`）跨刷新正则断点自动重算吸附边界，同步 42 个工具 schema 快照。
- **通用脱敏案例与门禁回归（`cases/`、`tests/`）**：
  - 新增脱敏案例 `cases/per-build-polymorphic-vmp-and-composite-gate-ablation.md` 并更新 `cases/README.md` 索引；扩充 `tests/test_skill_docs.py` 敏感词防回流列表并将脱敏案例基数门禁收紧至 4 篇。

## 兼容性

- 原有工作流、入口行数与模板目录保持不变；`patchErrorStackFormat` 为按读值证据按需启用的可选补丁；`inject`、`mock_response.body_file` 与 `url_pattern` + `find` 正则断点需配套 `camoufox-reverse-mcp >= 1.12.0`。

## 验证

- 52 项 Python 门禁测试（含站点词隔离、4 篇脱敏案例防回流、相对链接锚点与版本一致性检查）及三平台（Ubuntu / Windows / macOS）CI 全部通过。
- 本地 Node.js `vm` 实跑验证 `patchErrorStackFormat`（覆盖显式 `new Error()` 与引擎自抛 `TypeError`、无宿主帧泄漏、`Object.keys(Error)` 为空）及 `camoufox-reverse-mcp` 改写管线实测通过。
- `scripts/check-mcp-contract.py` 对 `camoufox-reverse-mcp v1.12.0` 校验通过（42 个工具 schema 一致），全部 Node/Python 模板自测通过。
