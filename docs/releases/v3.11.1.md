## 版本说明

JSVMP 探针日志改到页面主世界读取，配合 camoufox-reverse-mcp v1.9.3。之前有几处文档用默认的隔离世界读 `window.__mcp_jsvmp_log`，读不到页面脚本的记录。

## 主要变更

- `references/jsvmp-analysis.md` 的 5 处和 `references/phase-details.md` 的 1 处，改为 `evaluate_js("window.__mcp_jsvmp_log || []", world="main")`，和 `references/path-a-four-tools.md` 一致。
- README 里 transparent 模式的说明从“签名安全观察”改为“低干扰观察”：它在页面主世界替换 getter，严格的检测仍能发现。

## 兼容性

- 需要 camoufox-reverse-mcp v1.9.3。更早的版本把探针装在隔离世界，页面脚本的记录一直是空的，用哪个世界读都一样。
- `SKILL.md` 的 `mcp-compatible` 注明 `hook_jsvmp_interpreter` 需要 1.9.3，其余方法、模板和脚本不变。

## 验证

- 51 项 Python 脚本与文档门禁测试、40 项 Python 模板测试、3 项 Node 测试和 4 个模板离线测试通过。
- 全仓库检索 `__mcp_jsvmp_log`，所有读取处都带 `world="main"`。
